## 🚀 Featured Project

### ⚽ [Probabilistic Modelling of International Football: The 2026 World Cup](https://github.com/ssaaaam/world_cup_simulation)

My Bachelor's Thesis project, focused on developing a probabilistic framework to estimate the performance of national football teams and simulate the **2026 FIFA World Cup**.

The model extends the classical Elo rating system by:

* Separating each team's strength into **offensive and defensive components**
* Modelling match goals using **Poisson distributions**
* Introducing **confederation ratings** to propagate information between international competitions
* Estimating model parameters through an **iterative EM-inspired procedure**
* Evaluating predictive performance using **Brier Score, Log-Loss, RPS and calibration metrics**
* Running **100,000 Monte Carlo simulations** of the 2026 World Cup to estimate each team's probability of reaching every stage of the tournament

The project combines **statistical modelling, optimization, football analytics and large-scale simulation** in a complete end-to-end data science workflow.
